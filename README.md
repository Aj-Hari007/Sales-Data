# Retail Sales Analytics and Prediction System

## Project Overview

This project focuses on performing end-to-end data analysis and machine learning on a real-world retail sales dataset. The project includes data cleaning, exploratory data analysis (EDA), visualization, correlation analysis, and predictive modeling using machine learning algorithms.

The objective of this project is to analyze retail sales data, identify trends and patterns, and build predictive models to gain business insights and improve decision-making.

---

# Project Objectives

* Clean and preprocess retail sales data
* Perform exploratory data analysis (EDA)
* Visualize important trends and patterns
* Identify correlations and influencing factors
* Build predictive machine learning models
* Evaluate model performance using different metrics
* Generate meaningful business insights

# Tasks Performed

## 1. Data Cleaning

* Handled missing values
* Removed duplicate records
* Cleaned categorical text data
* Detected and removed outliers

## 2. Exploratory Data Analysis (EDA)

* Statistical summary analysis
* Distribution analysis
* Correlation analysis
* Trend and pattern identification
* Group-based analysis

## 3. Data Visualization

* Histogram distribution
* Boxplot analysis
* Correlation heatmap
* Scatter plots
* Count plots
* Confusion matrix
* ROC curve

## 4. Machine Learning

Algorithms used:

* Decision Tree Classifier
* Random Forest Classifier
* Linear Regression

## 5. Model Evaluation

Performance evaluated using:

* Accuracy Score
* Confusion Matrix
* Classification Report
* ROC Curve
* AUC Score
* Feature Importance Analysis
